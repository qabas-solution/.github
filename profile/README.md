# Qabas

**Qabas turns Braille into Arabic text.**

We are a student-built team creating tools that make Braille easier to read, learn, and share in Arabic.

## What we are building

- A platform that translates Braille into Arabic
- A web portal with a public website and an admin dashboard
- A mobile app
