# .github

Shared community health files for the **qabas-solution** organization.

| File | Purpose |
|---|---|
| `profile/README.md` | The organization profile shown on the organization page |
| `CONTRIBUTING.md` | How we work: branches, commits, pull requests |
| `SECURITY.md` | How to report a security problem |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |
| `.github/ISSUE_TEMPLATE/` | Default issue forms (bug report, feature request) |

These files apply to every repository in the organization that does not define its own.

> This repository is public because GitHub only applies default community health files from a public `.github` repository. Never put secrets, internal links, or private information here.
